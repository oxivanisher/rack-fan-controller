Third-party MicroPython libraries go here before uploading to the Pico.
Not vendored in this repo — see main README.md "Dependencies" section.

Needed:
- umqtt/simple.py  (from micropython-lib)
- microdot.py      (from https://github.com/miguelgrinberg/microdot)
- onewire.py + ds18x20.py (usually bundled with firmware; vendor only if missing)
